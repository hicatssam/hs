# Hicats Sam / HS Real Music

Official source repository for the Hicats Sam artist website.

## Current structure
- `index.html` — English homepage
- `profile.html` — English artist story
- `ar/index.html` — Arabic homepage
- `ar/profile.html` — Arabic artist story
- `images/` — website assets available in this repository
- `sitemap.xml` and `robots.txt` — search indexing

The current content is unified around Hicats Sam as the artist identity, with **FEAR** as the first major chapter, **AFTER FEAR** as the original next project, and **In the End** as a separate cover collaboration.

See `REMOTE-ASSETS.md` for the few oversized legacy image assets still referenced from the original public repository.
